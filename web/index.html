JSON 格式說明

檔案內容是一個陣列，每個物件是一個詞彙。必填：term_en、term_zh、definition、simple_explanation。

選填：category（任意分類，空白為「未分類」）、status（verified／pending／candidate，預設 pending）、example、research_note、source、sourceType、sourceDetail（沒有頁碼請留空）、is_core（true／false）、visibility（private／members／public，預設 private；舊格式 "is_shared": true 視為 public）。
